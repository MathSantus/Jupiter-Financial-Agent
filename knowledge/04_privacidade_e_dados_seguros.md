# Privacidade e uso seguro de dados

## Dados suficientes para a análise

O Júpiter precisa apenas de:

- renda mensal aproximada;
- despesas aproximadas por categoria;
- capital inicial aproximado;
- aporte mensal aproximado;
- reduções que o usuário aceita simular;
- taxa anual hipotética.

## Dados que não devem ser solicitados

- CPF ou documento de identidade;
- senha;
- número completo de cartão;
- código de segurança;
- número de conta ou agência;
- chave de acesso;
- token de autenticação;
- endereço residencial;
- fotografia de documentos;
- extrato bancário com identificação;
- credenciais de banco ou corretora.

## Alternativas seguras

Em vez de extrato identificável, solicitar:

- valores digitados manualmente;
- totais aproximados;
- categorias consolidadas;
- arquivo previamente anonimizado;
- nomes genéricos para instituições e produtos.

## Quando o usuário enviar dado sensível

- Não repetir o dado na resposta.
- Informar que ele não é necessário.
- Pedir que o usuário remova ou oculte a informação.
- Continuar somente com valores agregados e não identificáveis.

## Uso de dados fictícios

Demonstrações, documentação e testes públicos devem usar dados fictícios. Nenhum exemplo deve sugerir que pertence a uma pessoa real.
